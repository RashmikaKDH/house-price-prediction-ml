# 🏡 House Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts house prices in California using a **Linear Regression** model. It demonstrates the fundamental steps of a Machine Learning pipeline, including data exploration, model training, and evaluation.

## 🛠️ Technologies Used
* **Python** 
* **Pandas & NumPy** (Data Manipulation)
* **Scikit-Learn** (Machine Learning)
* **Matplotlib** (Data Visualization)
* **Jupyter Notebook** (Development Environment)

## 🚀 Results & Evaluation
The Linear Regression model was trained and tested on the California Housing Dataset.
* **Mean Squared Error (MSE):** ~0.55
* **R-Squared:** ~0.57 (The model explains approximately 57% of the variance in house prices).

## 💡 How to Run Locally
1. Clone this repository.
2. Create a virtual environment and activate it.
3. Run `pip install -r requirements.txt`.
4. Open the Jupyter Notebook and run the cells.
